# Dragon Gate Leap

A golden koi leaping into a dragon under the full moon — an entry for
make.fun's **"Make the AI judge excited"** bounty (ai-excited-01).

A colossal golden koi bursts out of the sea along a great diagonal arc, and
at the top of its leap it is becoming a dragon: branching horns, a flowing
mane, long whiskers, an open roaring mouth. Below it a tiny red torii gate
stands in the waves; behind it a huge full moon hangs in a burning
orange-to-indigo night sky while cherry blossom petals drift through the
air. One big diagonal, one focal point — built to hit at first glance and
still read at 300 pixels across.

## How it works

The image is drawn procedurally, not pasted in. `generate.py` is a small
hand-rolled rasteriser written in pure Python standard library (no Pillow,
no numpy): a raw RGB buffer, scanline polygon fills, discs along bezier
spines for the koi's body, fins, horns and whiskers, a soft radial glow
around the moon, and a PNG encoder built on `zlib`. It is deterministic —
two runs write byte-identical output.

`main.py` is the entry point: it renders the image to `$MAKEFUN_OUTPUT_DIR`
(`/output` in the grader) as `entry.png` (1024×1024, under 1 MiB).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Files

- `main.py` — entry point, writes `entry.png` to the output directory
- `generate.py` — the procedural drawing code and PNG writer
- `entry.png` — the rendered image (regenerated by running `main.py`)
- `LICENSE` — MIT
